fixwitness playground

Does your SQL change give the same answer on data you don't have yet?

Paste a query and the version an AI agent (or you) changed. fixwitness runs both on your tables and on variations of them: an empty value, a whole column of NULLs, a repeated row, another case, two rows of the same group. It shows every input where the answers differ.

Bug zoo:

Your change

Runs in your browser on SQLite. Nothing is sent anywhere.

Loading SQLite

About 1 MB, once.

What it varies

One table at a time, starting from its first rows: an empty value and a whole column of NULLs, a value copied from another row, a repeated row, the text in another case or with spaces, edge numbers and dates, and two rows of the same group with sub-cent or precision-edge amounts.

What a difference means

Both queries ran on the same tables and gave different results, or the changed one failed. The input shown is shrunk to the fewest rows that still show the difference.

Use it on your repository

The command-line tool checks dbt projects, warehouse SQL, pandas and polars code and scripts, on DuckDB, with a report and a reproduction for every finding.

pip install "git+https://github.com/batrarishab14/fixwitness"
fixwitness check
